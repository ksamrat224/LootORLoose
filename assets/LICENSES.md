# Visual and audio assets

The pixel-art SVGs in `app/public/art/` were created for this repository and may be used with the project. No third-party audio is included. Supplied brand artwork is documented below. Reference screenshots in `pictures/` are local design references and are not distributed.

## Supplied V4 brand assets

`app/public/brand/brand-logo.png` and `pixel-hero.png` were supplied by the project owner from local `pictures/` and explicitly requested for use in the application. Source copies remain local; only these approved copies ship. No broader third-party license or authorship is asserted here.

## Discovery journal

The six guardian lore entries and cosmetic route badges were written for this repository. Discovery lighting uses the existing original tiles and programmatic tinting. This polish adds no third-party visual or sound assets.
